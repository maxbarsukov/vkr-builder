# Демо-пример ВКР

| en :gb: | ru :ru: |
| ---- | ---- |

Полный рабочий пример: Markdown-главы, изображения и готовые артефакты сборки.
Текст ВКР описывает сам инструмент и демонстрирует поддерживаемые возможности.

## Быстрый старт

Из корня репозитория (где `main.py` и `config.yaml`):

```bash
./vkr-builder.sh build          # Linux/macOS
vkr-builder.bat build           # Windows
```

Движок выбирается сам: Word, если он установлен, иначе LibreOffice. Вместе с PDF:

```bash
./vkr-builder.sh build --pdf
```

Профиль `example` в `config.yaml` указывает на этот каталог.

## Что где показано

| Файл | На чём стоит посмотреть |
|------|-------------------------|
| `01-abbreviations.md`, `02-terms.md` | словарные разделы: одна строка на термин, сортировка по алфавиту |
| `03-introduction.md` | структурный раздел с каноническим заголовком |
| `04-chapter1.md` | нумерованная глава, подразделы, списки, 2 таблицы, цитирование по ключам |
| `05-chapter2.md` | 3 рисунка с подписями и ссылками, 8 формул, листинг из файла |
| `06-conclusion.md`, `07-sources.md` | заключение и список источников по первому упоминанию |
| `08-appendix-a.md` | три листинга из файлов |
| `09-appendix-b.md` | приложение с рисунками и своей нумерацией `Б.1`, `Б.2` |
| `10-appendix-c.md` | длинные таблицы: перенос с повтором шапки и подписью «Продолжение таблицы», плюс справочник конструкций разметки |

## Структура

| Путь | Назначение |
|------|------------|
| `md/` | Главы Markdown в порядке из конфига |
| `images/` | Изображения из Markdown |
| `listings/` | Исходники, которые главы подключают через `@listing` |
| `VKR-example.docx` | Собранный DOCX ([образец](VKR-example.docx)) |
| `VKR-example.pdf` | PDF при `--pdf` ([образец](VKR-example.pdf)) |

Собранные файлы закоммичены и обновляются вместе с исходниками, так что их
можно открыть, ничего не собирая. На время сборки в `md/` появляется
объединённый `_bundle.md`, после неё он удаляется.
