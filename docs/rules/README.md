# Правила проверок

| en :gb: | ru :ru: |
| ---- | ---- |
| [README.en.md](README.en.md) | README.md |

Каждая находка несёт **имя правила** — оно не меняется, когда меняется
формулировка сообщения. Имя видно в `--json` (поле `rule`), и именно его пишут
в директиве `@suppress`. Как подавлять находки — см. [Правила разметки](../llm-format/README.md).

Правила разнесены по этапам: этап определяет, какая команда выдает warning.

## Разметка — `lint` и пре-флайт внутри `build`, `watch`

| Правило | Находка | Что делать |
|---------|---------|------------|
| `unknown-reference` | ссылка `[рис:key]`, для которой нет подписи с таким ключом | добавить подпись или исправить ключ |
| `unknown-citation` | цитата, которой нет в списке источников | добавить источник или исправить номер/ключ |
| `duplicate-key` | один ключ у двух объектов | переименовать один |
| `uncited-source` | источник из списка, на который никто не ссылается | сослаться или удалить |
| `unreferenced-object` | рисунок, таблица или листинг, на который нет ссылки | добавить `[рис:key]` в текст |
| `caption-order` | подпись не с той стороны от объекта | у рисунка — после, у таблицы и листинга — перед |
| `caption-spacing` | рисунок и подпись слиплись в один абзац | разделить их пустой строкой — иначе рисунок в документ не попадёт |
| `comma-citation` | форма `[1, 2]` | по ГОСТ — `[1; 2]` |
| `spaced-range` | диапазон с пробелами: `6 - 7` | сомкнуть — `6-7`; если пробелы намеренные, погасить директивой |
| `table-columns` | строка таблицы с другим числом столбцов, чем шапка | выровнять число столбцов |
| `long-paragraph` | абзац длиннее предела | разбить |
| `empty-section` | заголовок без текста под ним | дописать текст |
| `structural-heading` | заголовок первого уровня не из структуры ГОСТ | исправить название раздела |
| `numbering-gap` | пропуск в явной нумерации объектов | нумеровать ключами, а не вручную |
| `dictionary-order` | сокращения или термины не по алфавиту | отсортировать или включить `build.sort_dictionary_lists` |
| `appendix-letter` | недопустимая или повторяющаяся буква приложения | запрещены **I**, **O** и **Ё З Й О Ч Ь Ы Ъ** |
| `listing-file` | файл `@listing` не читается или пуст | проверить путь относительно `listings_dir` и диапазон строк |

## Сборка — при записи документа

| Правило | Находка | Что делать |
|---------|---------|------------|
| `unknown-key` | ключ подписи или формулы, который нигде не определён | определить ключ или убрать скобки |
| `duplicate-source` | один номер или ключ источника дважды | оставить одну запись |
| `image` | изображение не прочиталось или не вставилось | проверить путь относительно `images_dir` |
| `metadata` | значение `metadata` не разобралось | даты: `2026-01-15` или `2026-01-15 10:30:00` |
| `table-continuation` | таблицу не удалось перенести на страницы | обычно ячейка выше страницы |
| `toc-unstable` | номера страниц не сошлись за отведённые проходы | сообщите об этом: почти всегда это ошибка вёрстки |
| `heading-mismatch` | заголовки документа разошлись с разметкой | пересобрать без `--skip-merge` |
| `page-numbering` | печатный номер первой страницы не тот | проверить `style.page.number_from` |
| `output-locked` | выходной файл занят другой программой | закрыть DOCX в Word; сборка сохранит копию с `-new` |
| `unknown-element` | элемент разметки, неизвестный сборщику | см. [Правила разметки](../llm-format/README.md) |

Четыре правила работают на обоих этапах — `unknown-reference`,
`unknown-citation`, `uncited-source` и `listing-file`. Линтер находит их в разметке, сборщик — ещё раз при записи
документа, поэтому директива на такое правило считается лишней только после
полной сборки, а не после одного `lint`.

## Готовый документ — `diagnose` и `build --diagnose`

| Правило | Находка | Что делать |
|---------|---------|------------|
| `figure-captions` | число рисунков и подписей не сходится | проверить, что у каждого рисунка есть подпись |
| `table-captions` | подписи таблиц не сходятся | то же для таблиц |
| `empty-heading` | заголовок без текста | дописать или убрать |
| `orphan-widow` | висячая строка на границе страниц | правится текстом; проверка best-effort |
